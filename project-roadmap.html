📋 STEP 2: DATA MODELS & SERVICES

Data Models & Services
📋 PLANNED
Objective: Create C# data models and service layer to replace JavaScript mock data generation.

Tasks

  • Create Data Models: BikeEntity, TripRecord, ZoneInfo, KPIMetrics, FleetStatus
  • Build Service Layer: IDataGenerationService, IKPIService, IZoneService, ITripService
  • Implement State Management: AppState class, StateContainer service
  • Update Dashboard Component: Inject services, Bind to C# data

Example Data Models

// Models to create: - BikeEntity (ID, Status, Location, VibrationLevel) - TripRecord (BikeID, StartTime, Duration, Zone) - ZoneInfo (Name, Coordinates, TripCount, AvgQuality) - KPIMetrics (aggregated statistics) - FleetStatus (Active, Idle, Maintenance counts)
Estimated Time: 2-3 days

📋 STEP 3: REAL-TIME DATA UPDATES

Real-time Data Updates
📋 PLANNED
Objective: Implement SignalR for true real-time data streaming from backend to dashboard.

Tasks

  • Setup SignalR Hub: Create ASP.NET Core backend, Implement DashboardHub
  • Backend Data Service: Background service for data generation, Hub methods
  • Client-Side Integration: SignalR client package, Connection lifecycle
  • Update Dashboard: Replace polling with SignalR events, Connection status UI
Estimated Time: 3-4 days

📋 STEP 4: INTERACTIVE FEATURES

Interactive Features
📋 PLANNED
Objective: Add user interaction capabilities for filtering, drilling down, and managing alerts.

Tasks

  • Filter Controls: Date range picker, Zone selector, Status filter, Vibration threshold slider
  • Drill-Down Views: KPI detail views, Zone detail pages, Bike detail modals
  • Bike Detail View: Full information, Trip history, Maintenance logs
  • Alert Management: Alert list with filtering, Acknowledge/dismiss alerts
  • User Preferences: Save filter preferences, Customize layout, Theme selection

📋 STEP 5: DATA PERSISTENCE

Data Persistence

Tasks

  • Database Design: Relational schema, EF Core migrations, Seed data
  • Entity Framework Core: DbContext, Entity configurations, Repositories
  • Data Import/Export: CSV import, Excel export, JSON API
  • Backend API: REST API for CRUD, Pagination, Search, Swagger docs
  • Client Updates: API calls, Loading states, Error handling
Estimated Time: 5-6 days
